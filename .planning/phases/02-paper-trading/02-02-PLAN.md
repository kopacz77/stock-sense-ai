# Plan 02-02: Strategy Loading API (PAPER-02)

## Objective

Fix the POST /api/paper/start endpoint to return 200 instead of 501 by implementing dynamic strategy loading from StrategyRegistry and starting the paper trading engine.

## Background

The current endpoint (lines 124-139 of paper-trading-api.ts) returns:
```typescript
return res.status(501).json({ error: "Start endpoint not fully implemented" });
```

The StrategyRegistry provides:
- `getStrategy(name, params)` - Returns `Strategy` interface
- Available strategies: 'mean-reversion', 'momentum'

The engine expects `BacktestStrategy` interface, so we need an adapter (similar to StrategyAdapter in backtest-commands.ts).

<task id="3" type="code">
<title>Implement POST /api/paper/start endpoint</title>
<description>
Rewrite the /api/paper/start handler (lines 124-139) to:
1. Extract `strategyName`, `symbols`, and optional `strategyParams` from request body
2. Validate that strategyName exists in StrategyRegistry using `hasStrategy()`
3. Get strategy instance: `const strategy = getStrategy(strategyName, strategyParams)`
4. Create adapter: `const backtestStrategy = new StrategyAdapter(strategy, strategyName)`
5. Call `await this.engine.start(backtestStrategy, symbols)`
6. Return 200 with success message and status

Handle errors:
- 400 if strategyName or symbols missing
- 400 if strategy not found (list available strategies)
- 500 if engine fails to start
</description>

<description>
Add a new endpoint to list available strategies:
```typescript
this.app.get("/api/paper/strategies", (req, res) => {
  const registry = StrategyRegistry.getInstance();
  const strategies = registry.getAllStrategyInfo();
  res.json({
    available: registry.listStrategies(),
    details: strategies.map(s => ({
      name: s.name,
      description: s.description,
      defaultParams: s.defaultParams
    }))
  });
});
```
This helps users discover what strategies they can use.
