# Plan 02-01: Real Market Data Integration (PAPER-01)

## Objective

Replace the mock `fetchMarketData()` method in PaperTradingEngine with real market data from MarketDataService. This enables paper trading to use actual prices from Alpha Vantage, Finnhub, or Yahoo Finance providers.

## Background

The paper trading engine currently generates random mock prices (lines 195-216 of paper-trading-engine.ts):
```typescript
price: 100 + Math.random() * 10, // Mock price
```

The MarketDataService already provides:
- `getHistoricalData(symbol, outputSize)` - Returns `HistoricalData[]`
- `getCurrentQuote(symbol)` - Returns `MarketData`
- `getFullAnalysisData(symbol)` - Combined quote + historical
- Provider fallback: Alpha Vantage -> Finnhub -> Yahoo Finance
