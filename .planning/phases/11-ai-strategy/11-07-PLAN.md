    Add exactly three endpoints to `src/web/server.ts`, registered in the same block as the `/api/monitoring/*` routes so they inherit the existing `/api` auth middleware — do NOT register them before that middleware and do NOT add a separate, looser path (ASVS V4: the strategy endpoints must require the same access level as monitoring, never less).

    `GET /api/strategy/candidates` — optional `?date=YYYY-MM-DD`, defaulting to today. It reads the persisted `candidates-YYYY-MM-DD.jsonl` for that date rather than re-running the engine (a browser request must not trigger a multi-second engine run with live provider fetches); when no file exists for the date, return `200` with empty `ranked`/`subThreshold`/`shadow` arrays and a `generated: false` flag so the page can tell "no run yet" from "ran and found nothing" — that distinction is the web equivalent of D-14's honest empty state. Include the day's VIX quote and `skippedTypes` when the run persisted them.

    `POST /api/strategy/candidates/:id/accept` and `POST /api/strategy/candidates/:id/skip` — validate the body with `StrategyAcceptSchema` / `StrategySkipSchema` (Zod, declared beside the existing `MonitoringStartSchema`), returning `400` with `{ error, details }` on a parse failure exactly as the monitoring routes do. Accept's schema: `entry`, `target`, `stop`, `sizeUsd` each an optional positive finite number; `note` an optional string capped at 500 characters. Skip's schema: `note` optional, same cap. Resolve `:id` through `DecisionLog.findCandidate`; an unknown id returns `404` with a clear message rather than writing anything. Reject a `sizeUsd` above twice the largest regime size for the configured `assumedEquity` with a `400` naming both numbers — the web form has no confirmation step, so unlike the CLI (which warns and proceeds) this boundary is enforced.

    Both handlers call the same `DecisionLog.recordAccept` / `recordSkip` the CLI calls. Do not duplicate the record-construction logic in the web layer; a decision made in the browser and one made in the terminal must be byte-identical in `decisions-*.jsonl` apart from timestamps.

    Treat `note` as an opaque string: store it verbatim, never interpolate it into a shell command, a `RegExp`, or a template evaluated at runtime.

    Verify the three endpoints with `curl` against a locally started dashboard, and record the exact commands and responses in the SUMMARY.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → `/api/strategy/*` | Untrusted HTTP request bodies reach decision-log writes |
| LLM-authored rationale text → rendered DOM | Model-generated strings are displayed in a browser |
| `:id` path parameter → file lookup | Operator/browser-supplied identifier used to resolve a persisted candidate |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-07-01 | Elevation of Privilege | New `/api/strategy/*` routes bypassing auth | high | mitigate | Routes are registered inside the same block as `/api/monitoring/*`, after the `/api` auth middleware, so they inherit `authMiddleware` when `AUTH_REQUIRED` and `optionalAuthMiddleware` otherwise — no separate mount path, no route-level opt-out |
| T-11-07-02 | Tampering | Unvalidated accept/skip request body | high | mitigate | Zod `StrategyAcceptSchema` / `StrategySkipSchema` with positive-finite number checks and a 500-character note cap; `400` with `details` on failure, mirroring `MonitoringStartSchema`. `sizeUsd` above 2x the largest regime size is rejected outright because the web form has no confirmation step |
| T-11-07-03 | Tampering | `:id` path parameter used to reach a file | medium | mitigate | `:id` is only ever compared against `candidateId` values read out of `candidates-*.jsonl`; it is never concatenated into a filesystem path. An unresolvable id returns `404` and writes nothing |
| T-11-07-04 | Information Disclosure | LLM-authored rationale rendered in the DOM | low | mitigate | React escapes text children by default; render rationale as a text node and never via `dangerouslySetInnerHTML` |
| T-11-07-05 | Denial of Service | A browser request triggering a live engine run with provider fetches | medium | mitigate | `GET /api/strategy/candidates` reads the persisted `candidates-*.jsonl` and never calls `generateCandidates`; producing candidates stays a deliberate `strategy run` invocation |
| T-11-07-06 | Repudiation | A web-originated decision indistinguishable from a fabricated one | low | accept | Both surfaces write through the same append-only `DecisionLog`; single-operator tool with no multi-user attribution requirement in v1 |
| T-11-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new packages — the page uses the already-installed React, framer-motion, lucide-react, react-hot-toast and the existing UI components. If an install becomes necessary, stop and run the Package Legitimacy Gate first |
</threat_model>
