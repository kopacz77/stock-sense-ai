## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM-authored `catalyst-flags-*.jsonl` rows → candidate rationale and direction | Model-generated `direction`, `confidence`, `magnitudePrior` and free-text derived fields drive a position's side and size |
| External calendar sources (FRED, Finnhub earnings, seed files) → `CatalystFlag` | Third-party release schedules become event dates the engine positions ahead of |
| `data/intel/` file tree → loader | An arbitrary or malformed file matching the catalyst-flags name pattern is parsed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-03-01 | Tampering | Malformed / hostile JSONL line in `catalyst-flags-*.jsonl` | medium | mitigate | The loader's per-line `try/catch` skips unparseable lines without aborting the file or the run; asserted by a Task-1 test case |
| T-11-03-02 | Tampering | LLM-authored `direction` / `confidence` drives trade side | medium | mitigate | Score is bounded to [0,1] by construction and the 0.4 floor keeps low-confidence emergent flags out of the ranked list; `uncertain` emits nothing and `binary` is halved per leg. The rationale names `calendar:` vs `article:` provenance so the operator sees which population a candidate came from before accepting |
| T-11-03-03 | Spoofing | A stale, re-appended catalyst row overwrites a refined one | medium | mitigate | Dedup keeps the row with the later `lastRefinedAt ?? firstSeenAt`, implemented once in `dedupeCatalystsById` and asserted against out-of-order input |
| T-11-03-04 | Information Disclosure | Catalyst rationale text printed to terminal | low | accept | Content is public news-derived text already stored on disk; single-operator local tool |
| T-11-03-05 | Denial of Service | Loader reads every `catalyst-flags-*.jsonl` file on every call | low | accept | 68 files / ~3.6k rows today; a full scan is milliseconds. Revisit if the archive exceeds roughly a year of files |
