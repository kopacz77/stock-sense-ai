    **Hardcode the param grids (from CONTEXT.md + RESEARCH.md):**

    Momentum: `shortMA ∈ [10, 15, 20, 30, 50]` × `minConfidence ∈ [55, 65, 75]`, with `longMA = 75` (locked — validator requires `shortMA < longMA`, so longMA=75 covers shortMA=50 safely). All other params at defaults.
    → **15 combos**

    MeanReversion: `rsiOversold ∈ [20, 25, 30, 35, 40]` × `rsiOverbought ∈ [60, 70, 80]`. Validator requires `rsiOversold < rsiOverbought`. Filter the cartesian product to exclude invalid combos (e.g., 40 × 60 OK because 40 < 60; 40 × 70 OK; etc. — actually all 15 combos satisfy oversold < overbought since min overbought=60 > max oversold=40). All other params at defaults.
    → **15 combos**

    ```typescript
    const MOMENTUM_GRID = [
      ...flatMap(shortMA in [10,15,20,30,50],
                 minConfidence in [55,65,75],
                 yield ({ shortMA, longMA: 75, minConfidence }))
    ];
    const MEANREV_GRID = [
      ...filtered cartesian of rsiOversold × rsiOverbought where oversold < overbought
    ];
    ```

    **Locked backtest config:**
    - `initialCapital: 100000`
    - `commission: new FixedCommissionModel(0)` — Alpaca $0/trade
    - `slippage: new FixedBPSSlippageModel(5)` — 5 BPS = 0.05% per side (per CONTEXT.md)
    - `startDate: new Date('2018-01-01')`
    - `endDate: new Date('2025-12-31')`
    - `fillOnClose: true` (engine default)
    - No leverage

    **Runner loop:**
    ```
    for ticker in UNIVERSE:
      bars = await marketDataService.fetchHistoricalData(ticker, startDate, endDate)
      if bars.length < 500: log warning and skip
      for (strategyName, grid) in [('momentum', MOMENTUM_GRID), ('meanReversion', MEANREV_GRID)]:
        for params in grid:
          try:
            strategy = createStrategyFactory(strategyName)(params)
            engine = new SimpleBacktestEngine(config, strategy)
            t0 = Date.now()
            result = await engine.run(ticker, bars)
            elapsedMs = Date.now() - t0
            perRegime = {
              bull: metricsByRegime(result, 'bull'),
              bear: metricsByRegime(result, 'bear'),
              highVol: metricsByRegime(result, 'highVol'),
            }
            record = {
              ticker,
              strategy: strategyName,
              params,
              elapsedMs,
              fullMetrics: result.metrics,
              regimeMetrics: perRegime,
              totalTrades: result.metrics.totalTrades,
              tradesPerYear: result.metrics.totalTrades / 8,
            }
            appendJsonl(resultsPath, record)
            runCount += 1
            if runCount % 50 === 0: log progress (runs / estimatedTotal)
          catch err:
            log error with ticker + strategy + params + message
            appendJsonl(resultsPath, { ...partialRecord, error: err.message })
            continue  # don't halt the sweep
    ```

    - Skip any (ticker, strategy, params) combo already in that set.
    - This means re-running the script picks up where it left off.
